# Sistema de Biblioteca

Atividade desenvolvida durante o curso de Full Stack da +praTi.

O projeto consiste na implementação de um sistema de biblioteca utilizando Java e PostgreSQL.

## Atividade

### Java - POO

- Classes abstratas
- Herança
- Polimorfismo
- Controle de empréstimos e devoluções
- Limite de empréstimos para alunos e professores

### PostgreSQL

- Modelagem das tabelas `item`, `usuario` e `emprestimo`
- Inserção de dados para teste
- Consultas SQL

## Estrutura

- `src` → arquivos Java
- `banco` → scripts SQL

## Tecnologias

- Java
- PostgreSQL
- IntelliJ IDEA
- Git e GitHub
